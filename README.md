# social-assets

Public images for Collisa social posts (LinkedIn, Instagram, TikTok), scheduled through Buffer.
Buffer needs a stable public URL per image; files here are served via `raw.githubusercontent.com`.

- `YYYY/MM/<channel>-<topic>.png|pdf`: published assets
- `tools/render_example.py`: HTML → PNG renderer in the collisa.be brand style
  (Poppins, Fira Code, paper `#f7f7f7`, ink `#141414`, cyan `#5ce1e6`, teal `#0b6e75`)

Brand tokens come from `resources/css/app.css` in the collisa-website project.
